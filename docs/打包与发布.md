# 打包与发布

这个目录就是一个完整的 GitHub 仓库：源码在根目录，`npm run build` 把 Vue 3 单页应用打包成 `dist/`（单个 IIFE + CSS，双击 `dist/index.html` 就能离线用），
联网版走 GitHub Pages（`gh-pages` 分支）。

---

## 一、开发与构建

```bash
export PATH=/path/to/node20+/bin:$PATH     # Vite 7 需要 Node ≥ 20.19
npm install                                # 只装 vue / vite / plugin-vue
npm run dev                                # http://127.0.0.1:5177/  改代码热更新
npm test                                   # 四个内核：319 项
npm run build                              # 产出 dist/
npm run test:dom                           # 用 headless Chrome 跑 dist 的 36 项 DOM 断言
```

`dist/` 里有：`index.html`、`assets/app.js`（约 210 KB）、`assets/style.css`、`media/`（首页缩略图）、
`docs/`（所有 Markdown 说明书 + `采购清单.csv` + `尺寸图.png` + `petg/`）。`docs/` 由 `vite.config.js` 里的
`diy-docs` 插件在构建结束时自动拷贝，所以**改完文档要重新 build** 才会同步到离线包。

## 二、桌面快捷方式（macOS）

```bash
bash tools/创建桌面快捷方式.command        # 生成 ~/Desktop/自制家具.app，指向 dist/index.html
```

| 图标 | 双击后的效果 |
|---|---|
| **自制家具.app** | 直接打开 `dist/index.html`（不弹终端窗口，图标用的项目截图） |
| 打开项目首页.command | 终端里 `open dist/index.html`，给习惯命令行的人用；`--check` 只打印解析到的路径 |

两者都存**绝对路径**，项目不要随便改名/搬家；真搬了重新跑一次脚本即可（加 `--yes` 跳过确认弹窗）。
删掉桌面上那两个图标不影响项目本身。如果还没 build，先 `npm run build`，脚本会提示找不到 `dist/index.html`。

## 三、上传到 GitHub

仓库：**<https://github.com/kenneth-kun/diy-aluminum-extrusion-furniture>**

> 本机已通过 SSH key 推送成功（HTTPS 那条路走的是 keychain 里的旧 token，会 403；遇到同样问题执行

中文文件名没问题，GitHub 会自动做 URL 编码。

## 四、GitHub Pages（在线版）

因为构建产物不入 `main`，在线版用一条 `gh-pages` 分支（`dist/` 的内容直接作为该分支根目录）：

```bash
npm run build
rm -rf .deploy && mkdir .deploy
cp -R dist/. .deploy/ && touch .deploy/.nojekyll
cd .deploy
git init -q && git add -A && git commit -qm "deploy: dist"
git push -f git@github.com:kenneth-kun/diy-aluminum-extrusion-furniture.git HEAD:gh-pages
cd .. && rm -rf .deploy
```

然后仓库 → **Settings → Pages** → Source `Deploy from a branch` → Branch **`gh-pages`** / `/(root)` → Save。

一两分钟后：

```
https://kenneth-kun.github.io/diy-aluminum-extrusion-furniture/
```

`.nojekyll` 别删——它让 Pages 跳过 Jekyll 处理，避免文件名里带下划线/中文时的坑。

## 五、仓库里都放了什么

- **应用**：`src/`（Vue 3 SFC + 四个计算内核 + 四个 SVG 正视图 + 9 个组件 + 设计系统）、根 `index.html` 与 `vite.config.js`；
- **测试**：`tests/*.test.js`（Node，零依赖，319 项）+ `tests/run-dom-tests.sh`（headless Chrome，36 项）；
- **文档**：`README.md`、`材料清单.md`、`铝型材柜.md`、`铝型材桌面柜.md`、`亚克力展示盒.md`、`petg/打印说明.md`、本文件；
- **数据**：`采购清单.csv`（UTF-8 BOM，Excel 双击不乱码）、`petg/stl/*.stl`（二进制 STL，5 个文件不到 40 KB）；
- **图**：`public/media/thumb-*.png`（首页缩略图）、`public/media/hub-preview.png`、`尺寸图.png`、`petg/preview_*.png`（合计约 2 MB，克隆很快）。

不含：小红书原帖照片（版权在原帖作者）、`node_modules/`、`dist/`、OrcaSlicer/BambuStudio 等本地工具、`__pycache__`、切片产物（`.3mf` / `.gcode`）。

## 六、常见问题

| 问题 | 原因 / 处理 |
|---|---|
| 双击 `dist/index.html` 白屏 | 先确认构建过；构建产物是 IIFE + 普通 `defer` 脚本，`file://` 下可用。若自己改过 Vite 配置，别把脚本改回 `type="module"` |
| 双击 `index.html`（根目录）白屏 | 根目录那个是 Vite 开发入口，需要 `npm run dev`；离线用 `dist/index.html` |
| 复制出来的链接打不开别人的机器 | `file://` 链接依赖绝对路径，分享给别人请用 Pages 地址 |
| 1688 搜索链接关键词乱码 | 已按 GBK 编码逐字转换；自己改关键词时，表里没有的字会退回 UTF-8 并加 `&charset=utf8` |
| `npm` 报 `Log files were not written … ~/.npm/_logs` | 这机器上 `~/.npm` 不可写，加 `--cache /tmp/npmcache` |
| `npm run build` 报 `Cannot find module 'node:fs'` 之类 | PATH 里的 node 太老（v14），换成 Node ≥ 20.19 |
| Excel 打开 CSV 中文乱码 | 文件是 UTF-8 **带 BOM**，Excel 直接双击即可 |
| `git push` 403 | 用 SSH remote（见上），或 PAT 代替密码 |
| Pages 打开 404 | 确认 Source 是 `gh-pages` / `/(root)`，且分支里根目录有 `index.html` 与 `.nojekyll` |
| 搬家后桌面图标失效 | 重新跑 `bash tools/创建桌面快捷方式.command` |
